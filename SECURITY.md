# Security policy

Please do not open a public issue for a suspected vulnerability involving
authentication bypass, request smuggling, path traversal, credential exposure,
training-data disclosure, or model artifact leakage.

Report it privately through GitHub's security-advisory flow for this repository.
Include affected versions, reproduction steps, impact, and any suggested
mitigation. Do not include real customer audio, transcripts, API keys, or
private model artifacts in a report.

Security fixes are prioritized for the latest main branch. The project does
not currently promise backports for older snapshots.
